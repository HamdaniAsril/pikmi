01 · how it works

You describe a feeling, pikmi suggests a few styles, and your agent builds with the one you pick.

  1. 1you

    Describe the mood

    Tell your agent how it should feel, in English or Indonesian. No style names needed.

    in · moodrec

    01“make it calm and airy”

    02“bikin kayak poster punk”

  2. 2pikmi

    Pick one of three

    pikmi suggests up to three matching styles with a short reason. You choose one, or skip.

    sel · 3 matches1/3

    07japanese minimal◀

    09soft wash

    04ledger blue

    match92%
  3. 3your agent

    Build with that style

    Your agent uses only the chosen style, builds the design, then checks it against the style’s rules.

03 · install

In Claude Code, add the marketplace and install the plugin. Then ask for a design the way you would describe it to a person.

/plugin marketplace add HamdaniAsril/pikmi
/plugin install pikmi@pikmi

The repository is private for now, so installing needs a GitHub account with access to it.

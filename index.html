01 · how it works

Three steps, one question. pikmi stays quiet when your project already has its own look.

  1. mood01

    say the mood

    Start a new design or ask for a new look, in English or Indonesian. pikmi matches your mood words against every style in its catalog.

    “make it calm and airy”

    “bikin kayak poster punk”

  2. pick02

    pick one of three

    It opens the previews and offers up to three styles, each with a one-line reason and a card of its palette and fonts. Or you carry on without pikmi.

    Night Circuit · dark

    palette#0A0A0F page · #F2F7FA text · #00F0FF accent

    fontsChakra Petch / Share Tech Mono

  3. build03

    build with one

    Your agent loads only the chosen style and the rules for your medium, builds, then checks the result against the style’s checklist. Web projects keep a marker so later sessions continue the look.

    tokens.css

    /* pikmi: night-circuit */

03 · install

In Claude Code, add the marketplace and install the plugin. Then ask for a design the way you would describe it to a person.

/plugin marketplace add HamdaniAsril/pikmi
/plugin install pikmi@pikmi

The repository is private for now, so installing needs a GitHub account with access to it.

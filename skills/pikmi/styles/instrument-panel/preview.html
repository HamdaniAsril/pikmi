01 ·three kinds of control

Every control has one job. Keys choose, encoders set, the round button records.

keys choose

pick the input

Numbered keys pick one thing at a time. Hold shift for the second job printed below the key.

encoders set

turn to set a value

Three encoders, one per value. The cap color tells you which one you are holding.

one button records

press once to record

The orange button is the only thing that starts a take. The switch turns live monitoring on and off.

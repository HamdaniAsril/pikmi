# pikmi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun skill `pikmi`: satu skill pengarah yang menawarkan 13 style desain lintas UI, slides, social, dan app, lengkap dengan katalog kata kunci, foundations per medium, dan pemeriksa otomatis.

**Architecture:** Plugin Claude Code dengan satu skill (`skills/pikmi/SKILL.md`) yang membaca `catalog.json`, lalu hanya membuka folder style yang dipilih (`STYLE.md`, `tokens.css`, `tokens.json`, `preview.html`) dan `foundations/<medium>.md`. `scripts/check.py` (stdlib Python) menjaga konsistensi katalog, token, kontras, dan aturan antislop yang bisa dicek mesin.

**Tech Stack:** Markdown, JSON, CSS custom properties, HTML statis, Google Fonts, Python 3.9 stdlib (`unittest`).

**Spec:** `docs/superpowers/specs/2026-10-23-pikmi-design.md`

## Global Constraints

- Nama skill `pikmi`; hanya muncul di `plugin.json`, `marketplace.json`, folder `skills/pikmi/`, baris `name:` SKILL.md, dan README.
- Isi skill (SKILL.md, STYLE.md, catalog summary, foundations) berbahasa Inggris; kata kunci EN + ID.
- `skills/pikmi/SKILL.md` maksimal 149 baris; `description` maksimal 1024 karakter.
- File di folder style bernama `STYLE.md`, tidak pernah `SKILL.md`.
- Font hanya dari Google Fonts.
- Tidak ada em dash (—) di SKILL.md, foundations, catalog.json, STYLE.md, preview.html. En dash (–) boleh.
- `hard prompt/` hanya referensi: tidak ada kalimat, template HTML, atau checklist yang disalin; folder masuk `.gitignore`.
- Nama, logo, atau produk brand tidak muncul di STYLE.md, preview.html, tokens.css, maupun tokens.json (dicek lewat `brand_terms`).
- Semua style lolos antislop: palet per halaman 2–3 inti + 1 aksen; glow dan blur kaca maksimal 1–2 elemen; bayangan hanya untuk elevasi; radius bertingkat; pola latar hanya dengan alasan dan di satu permukaan; animasi dengan tujuan + `prefers-reduced-motion`; kontras WCAG AA; font bukan pilihan bawaan AI (Inter, Geist, Space Grotesk, JetBrains Mono, Fira Code) kecuali ada alasan.
- Python harus jalan di 3.9 (pakai `from __future__ import annotations`), tanpa dependensi luar.
- Kerja di branch `feat/pikmi`; commit per task.

## Review Focus

1. Permintaan berbahasa Indonesia campur slang tanpa kata kunci persis ("bikin kayak game sci-fi jadul"): pikmi tetap menawarkan style terdekat dan bilang tidak ada yang persis. Dites di Task 16 (eval E07).
2. User minta tema gelap untuk style yang hanya punya tema terang ("watercolor tapi dark mode"): pikmi bilang tidak tersedia dan menawarkan style yang punya tema gelap. Dites di Task 16 (eval E12).
3. `preview.html` dibuka di layar 375px: tidak ada scroll horizontal. Dites di setiap task style (langkah S6).
4. Token tembus pandang (rgba, `#RRGGBBAA`) di tabel kontras: rasio dihitung setelah warna digabung ke latarnya. Dites di Task 1 (`test_contrast_translucent`).
5. Proyek sudah bertanda `/* pikmi: watercolor */`, lalu user minta "ganti tampilan jadi cyberpunk": pikmi tidak diam, melainkan menawarkan/menerapkan style baru dan memperbarui penanda. Dites di Task 16 (eval E19).

## Shared formats (dipakai semua task style)

**tokens.json**

```json
{
  "name": "<id>",
  "title": "<Name>",
  "fonts":     { "<role>": { "family": "<Google Font>", "weights": [400, 700] } },
  "typeScale": { "label": 11, "caption": 12, "body": 16, "lead": 18, "h3": 22, "h2": 32, "h1": 48, "display": 88 },
  "tracking":  { "<k>": 1.5 },
  "radius":    { "<k>": 4 },
  "space":     { "xs": 4, "sm": 8, "md": 12, "lg": 24, "xl": 48 },
  "colors":    { "<k>": "#RRGGBB" },
  "effects":   { "<k>": "<css value>" },
  "themes":    { "<theme>": { "page": "", "panel": "", "card": "", "rule": "", "text": "", "text-muted": "",
                              "accent": "", "on-accent": "", "link": "", "danger": "" } }
}
```

**tokens.css** selalu diawali baris `/* pikmi: <id> */`, lalu komentar berisi nama style dan URL Google Fonts. Baris pertama ini sekaligus penanda proyek: saat agent menyalin tokens.css ke proyek user, penandanya ikut.

Pemetaan ke CSS (yang dicek `check.py`): `fonts.k` → `--font-k` (nilai CSS diawali `"<family>"`); `typeScale.k` → `--type-k: <n>px`; `tracking.k` → `--tracking-k: <n>px`; `radius.k` → `--radius-k: <n>px`; `space.k` → `--space-k: <n>px`; `colors.k` dan `effects.k` → `--k` apa adanya; `themes.<t>.k` → `--k`. Tema pertama di `catalog.themes` ditulis di `:root`; tema lain di `[data-theme="<t>"]` dan hanya berisi role yang berbeda. Semua grup opsional kecuali `name`, `title`, `fonts`, `themes`. Setiap tema wajib punya 10 role di atas; role tambahan khas style boleh. Nilai dibandingkan tanpa beda huruf besar/kecil dan spasi.

**STYLE.md**: heading wajib, urut: `## Identity` (diakhiri baris `Dial: ENERGY n / RHYTHM n / MOTION n`), `## Visual vocabulary`, `## Reasons`, `## Token usage`, `## Components`, `## Recipes` (dengan `### UI`, `### Slides`, `### Social`, `### App` untuk setiap medium di katalog), `## Outside CSS`, `## Contrast rules (checked)`, `## Pitfalls`, `## Checklist`.

Tabel kontras (satu-satunya bagian yang diparse):

```
| Text | On | Theme | Ratio | Rule |
| --- | --- | --- | --- | --- |
| `--on-accent` | `--accent` | light | 5.67 | Orange is a fill with black text. |
```

Sel `Text`/`On` berisi token (`--x`) atau warna literal (`#FFFFFF`, `rgba(...)`). Token dicari dulu di role tema pada kolom `Theme`, lalu di `colors`. Warna tembus pandang di `Text` digabung ke `On`; warna tembus pandang di `On` digabung ke `--page` tema itu. `Ratio` dua desimal, toleransi 0.01. Baris boleh berisi pasangan yang gagal (aturan "jangan"); yang dicek hanya ketepatan angkanya.

**preview.html**: dokumen mandiri; `<link rel="stylesheet" href="tokens.css">`; satu `<link>` Google Fonts; elemen `id="components"` dan `id="<medium>"` untuk setiap medium di katalog (`ui`, `slides`, `social`, `app`). Kanvas contoh: slide `aspect-ratio: 16 / 9`, post `4 / 5`, layar app `9 / 19.5`, diperkecil supaya muat di 375px. Kalau style punya dua tema, ada tombol ganti tema yang benar-benar mengubah `data-theme` di `<html>`.

**Entri catalog.json**: lihat bagian 6 spec. Field wajib: `id` (`^[a-z0-9-]+$`), `name`, `summary`, `keywords.en`, `keywords.id` (list tidak kosong), `media` (subset dari `ui`, `slides`, `social`, `app`), `themes` (subset unik dari `light`, `dark`), `preview` (= `styles/<id>/preview.html`), `brand_terms` (list, boleh kosong).
